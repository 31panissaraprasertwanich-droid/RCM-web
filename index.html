การวิเคราะห์ FMEA และการคำนวณ RPN (Risk Priority Number)

ตารางวิเคราะห์รูปแบบความเสียหาย ผลกระทบ และการประเมินความเสี่ยง โดยคำนวณจากสูตร: RPN = S × O × D

เกณฑ์การประเมิน (1 - 10 Score):

• Severity (S): ระดับความรุนแรงของผลกระทบต่อระบบไฟฟ้า
• Occurrence (O): โอกาสหรือความถี่ของการเกิดความเสียหาย
• Detection (D): โอกาสในการตรวจพบความผิดปกติก่อนเกิดเหตุขัดข้อง

อุปกรณ์ รูปแบบความเสียหาย (Failure Mode) ผลกระทบ (Failure Effect) S สาเหตุ (Failure Cause) O การตรวจสอบปัจจุบัน (Current Controls) D RPN (S×O×D) ระดับความเสี่ยง

การคำนวณดัชนีสุขภาพอุปกรณ์ (Health Index - HI)

ดัชนีสุขภาพ (HI) ใช้ประเมินสภาพปัจจุบันของหม้อแปลงและ GIS เพื่อประกอบการตัดสินใจวางแผนซ่อมบำรุงเชิงพยากรณ์ (Predictive Maintenance)

สูตรการคำนวณ Health Index (HI):

HI = $\sum (W_i \times C_i)$ / $\sum W_i$ หรือคำนวณจากน้ำหนักคะแนนผลการทดสอบเชิงลึก

โดยที่ $W_i$ คือค่าน้ำหนักความสำคัญของแต่ละหัวข้อทดสอบ และ $C_i$ คือคะแนนสภาพของหัวข้อนั้นๆ (คะแนนรวม 0 - 100 โดย 100 คือสภาพสมบูรณ์ที่สุด)

เกณฑ์การแปลผลคะแนน Health Index (HI):

  • 85.0 - 100.0 (Normal / Very Good): อุปกรณ์ปกติ ดำเนินการบำรุงรักษาตามวาระปกติ (Time-based)
  • 70.0 - 84.9 (Good / Attention): เริ่มเสื่อมสภาพเล็กน้อย เฝ้าระวังพารามิเตอร์สำคัญ
  • 50.0 - 69.9 (Medium / Warning): เสื่อมสภาพปานกลาง วางแผนตรวจสอบเชิงลึกหรือทำ PM เร็วขึ้น
  • < 50.0 (Critical / Poor): สภาพวิกฤต มีความเสี่ยงสูง เร่งรัดวางแผนซ่อมบำรุงหรือเปลี่ยนทดแทนด่วน
