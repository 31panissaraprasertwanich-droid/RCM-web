ผลการวิเคราะห์ DGA ทั้ง 6 วิธีตามมาตรฐานวิศวกรรมสากล

แสดงผลการคำนวณและเกณฑ์การประเมินเชิงลึกของแต่ละวิธี

1. IEEE Method (Std. C57.104) Concentration Limits

หลักการคำนวณ: ประเมินจากปริมาณความเข้มข้นของก๊าซแต่ละตัวเทียบกับค่ามาตรฐาน (Typical Concentration Values) และคำนวณอัตราการเกิดก๊าซ (Generating Rate) ต่อวัน

ผลการประเมิน:
2. Roger’s Ratio Method Ratio Code

หลักการคำนวณ: คำนวณอัตราส่วนก๊าซ 3 ชุด ได้แก่ C2H2 / C2H4, CH4 / H2 และ C2H4 / C2H6 แล้วนำมาแปลงค่าเป็นรหัสโค้ด (Ratio Codes: 0, 1, 2) เพื่อเทียบตารางวินิจฉัย

ผลการประเมิน:
3. Doernenburg Ratio Method 4 Gas Ratios

หลักการคำนวณ: ใช้ก๊าซ 5 ชนิดคำนวณอัตราส่วน 4 ชุด ได้แก่ CH4 / H2, C2H2 / C2H4, C2H2 / CH4 และ C2H6 / C2H2 เพื่อจำแนกประเภทความผิดปกติภายในหม้อแปลง

ผลการประเมิน:
4. Key Gas Method Dominant Gas

หลักการคำนวณ: วิเคราะห์หาว่าก๊าซชนิดใดที่มีปริมาณสัดส่วนสูงเด่นชัดที่สุด (Dominant Key Gas) ซึ่งก๊าซแต่ละตัวจะชี้เป้าจุดกำเนิดความเสียหายเฉพาะ เช่น Acetylene ชี้การอาร์ก

ผลการประเมิน:
5. IEC Method (IEC 60599) IEC Ratio Codes

หลักการคำนวณ: พัฒนาต่อยอดจาก Roger's โดยปรับช่วงขอบเขตอัตราส่วนก๊าซ 3 ตัว ได้แก่ I1 (C2H2 / C2H4), I2 (CH4 / H2) และ I3 (C2H4 / C2H6) ให้มีความแม่นยำตามมาตรฐานสากล

ผลการประเมิน:
6. Duval Triangle Method Percentage Coordinates

หลักการคำนวณ: แปลงค่าปริมาณก๊าซ CH4, C2H2 และ C2H4 ให้เป็นค่าเปอร์เซ็นต์รวม 100% แล้วนำไปพล็อตลงบนพิกัดสามเหลี่ยมเพื่อชี้โซนความเสียหาย (เช่น โซน T3 หรือ D1)
